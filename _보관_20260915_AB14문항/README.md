# 보관 — A/B 2안 14문항 산출물 (2026-09-15 이전)

2026-09-15 사용자 지시 *"앞으로 14문제 말고 7문제만 만들어 원고 한 개당 7문항만 나오게"*로
**원고 1건 = 7문항**으로 바뀌면서, 그때까지 만들어 둔 12건의 **14문항 원본**을 여기에 옮겨 두었다.

- `퀴즈데이터/*.json` — 7슬롯 × A안·B안 = 14문항 (옛 구조: `slots[i].A` / `.B`)
- `퀴즈CSV/*.csv` — 14행 · 17열, `문항 번호`가 `A1`~`A7`·`B1`~`B7`

`산출물/`의 같은 이름 파일은 **7문항으로 줄인 판**이다. 어느 안에서 왔는지는 각 JSON의
`meta.축약`과 슬롯의 `출처`(`1A`·`7B` 등)에 적혀 있다.

**이 폴더는 참고용이다.** `산출물/`이 아니므로 검토·집계 대상이 아니고, 여기 있는 문항을
CSV에 반영하지 않는다 (`_보관_20260828_구규칙/`과 같은 취급).
