# 도구 사용법

## 대시보드를 최신 CSV로 맞추기

**`대시보드_새로고침.bat` 더블클릭.**

`산출물/대단원별/*.csv` 9개를 다시 집계해서 `산출물/퀴즈제작현황_대시보드_v2.html`을 새로 만들고,
기본 브라우저로 열어 줍니다. 창은 3초 뒤 자동으로 닫힙니다.

CSV를 여러 번 고칠 예정이면 **`대시보드_자동감시.bat`**을 실행해 두세요. 창을 열어 둔 동안
CSV를 저장할 때마다 대시보드를 자동으로 다시 만듭니다. 창을 닫으면 감시가 끝납니다.

> 첫 실행에 Node.js가 필요합니다. 없으면 안내 문구가 뜨니 https://nodejs.org 에서 LTS 버전을
> 기본 옵션으로 한 번만 설치하세요.

## 퀴즈 JSON이 제대로 만들어졌는지 검사하기

```
node "산출물/도구/퀴즈JSON검증.js"                     ← 퀴즈데이터 전부 검사
node "산출물/도구/퀴즈JSON검증.js" <파일.json>          ← 한 건만 검사
```

`퀴즈생성자`는 파일을 쓰지 못해서 **사람이 결과를 JSON으로 옮겨 담습니다.** 그 과정에서 정답 번호를
잘못 적으면 미리보기가 **틀린 답을 정답으로 표시**합니다. JSON을 저장한 직후 이 명령을 돌리세요.

검사 항목: 7문항 고정 배열 · 정답 번호 범위 · 복수 정답 2개 · 순서배열 정답이 1~4 순열인지 ·
순서배열 검수 정보의 `정답 1`이 라벨 형식(`나-라-가-다`)인지 · 직접 입력의 고정 발문과 빈칸 밑줄 표기(띄어쓰기 포함) · 5번 슬롯의 `exFirst` 없음 · A안·B안 정답 용어 분리 ·
예문 미사용 칸의 `-` 표기.

> **구조만 봅니다.** 정답이 원고 내용에 비추어 맞는지는 검사할 수 없으니, 미리보기에서 직접 풀어보며
> 확인해야 합니다.

## 왜 HTML을 열 때 자동으로 동기화되지 않나

**브라우저는 로컬 파일(`file://`)로 열린 HTML이 다른 로컬 파일을 읽는 것을 막습니다.** 보안 정책이라
설정으로 우회할 수 없습니다. 그래서 대시보드 HTML 혼자서는 CSV를 다시 읽을 방법이 없고, 화면의
수치는 **만들어진 시점의 스냅샷**입니다(화면 상단에 집계 날짜가 찍혀 있습니다).

`.bat`을 더블클릭하는 방식은 **집계 → HTML 생성 → 열기**를 한 번에 하기 때문에, 결과적으로
"열면 최신"이 됩니다. 순서만 뒤바뀐 셈입니다.

진짜로 "HTML을 열면 그 자리에서 CSV를 읽는" 방식을 원하면 로컬 웹서버를 띄우는 방법이 있습니다
(이 폴더에는 아직 만들어 두지 않았습니다). 대신 대시보드를 볼 때마다 서버 창을 켜 둬야 합니다.

## 이 폴더의 파일

| 파일 | 역할 |
|---|---|
| `대시보드_새로고침.bat` | 더블클릭용. 한 번 집계하고 브라우저로 연다 |
| `대시보드_자동감시.bat` | 더블클릭용. 대단원 CSV·퀴즈데이터·미리보기·원고·목차 CSV가 바뀔 때마다 자동으로 다시 만든다 |
| `build-dashboard.js` | 실제 집계·생성 로직 (화면 **구조**를 바꾸려면 여기) |
| `dashboard.css` | 대시보드 디자인 (**색·여백·폰트**를 바꾸려면 여기) |

`퀴즈제작현황_대시보드_v2.html`은 **자동 생성 파일**입니다. 직접 고치면 다음 새로고침에서
사라지니, 위의 `build-dashboard.js`나 `dashboard.css`를 고치세요.

## 실행할 때 같이 확인해 주는 것

- **7문항 중 일부만 채워진 아티클**이 있으면 경고합니다. 팀 시트에 붙여넣기 전에 확인하세요
  (파일 잠김으로 절반만 반영된 사고가 두 번 있었습니다 — `기록/LESSONS.md` 참고).
- **CSV에 반영된 문항이 그 아티클의 미리보기 후보(A안·B안 14개)와 아직 같은지** 대조합니다.
  대조하는 칸은 **문제·예문·정답해설 세 칸**이고, 정답·보기 칸은 보지 않습니다.
  달라졌으면 경고합니다 — CSV만 고치고 미리보기를 갱신하지 않으면 두 화면이 서로 다른 문항을
  보여주게 됩니다. (2026-09-10 이전에는 「A. 특수 상대성 이론」 미리보기 하나만 대조했는데,
  그 파일이 이관 때 빠지면서 검사가 죽어 있었습니다.)
- **미리보기 HTML이 퀴즈데이터 JSON보다 낡지 않았는지** 대조합니다. JSON만 고치고
  `미리보기생성.js`를 다시 돌리지 않으면 사람이 보는 화면만 옛 문항으로 남습니다.
- 대단원 CSV 아티클 수와 목차 CSV 아티클 수가 어긋나면 **생성을 중단**합니다. 틀린 수치를 만드는
  것보다 멈추는 게 안전하기 때문입니다. 대단원 CSV의 **두 자리 번호가 겹치거나 목차 순서와
  어긋나도** 중단합니다 (`01_… - 복사본.csv` 같은 사본이 폴더에 남아 있을 때).
- 대단원별 폴더에 **번호로 시작하지 않는 CSV**(예: `퀴즈샘플_260831.csv`)가 있으면 집계에서
  제외하고 그 사실을 알려 줍니다. 예전에는 이런 파일 하나 때문에 생성이 통째로 멈췄습니다.
- 대단원 CSV **전 행의 열 수가 17인지** 셉니다 (예전에는 헤더 한 줄만 봤습니다).
- 대시보드 HTML이 다른 프로그램에 열려 잠겨 있으면 무엇을 닫아야 하는지 알려 줍니다.

## 건드리지 않는 것

- `재료/` 안의 파일은 **읽기만** 합니다 (CLAUDE.md 규칙 2번).
- `산출물/대단원별/*.csv`도 **읽기만** 합니다. 이 도구는 CSV를 쓰지 않습니다.
- `산출물/퀴즈데이터/*.json`·`산출물/퀴즈미리보기/*.html`도 **읽기만** 합니다.
- 쓰는 파일은 `산출물/퀴즈제작현황_대시보드_v2.html` **하나뿐**입니다.
